# Experiments

Experiments are bounded investigations, not hidden production changes.

## Protocol

- ID
- Question
- Hypothesis
- Setup
- Input
- Expected
- Actual
- Evidence
- Failure / surprise
- Interpretation
- Alternative explanation
- Lesson
- Candidate change
- Verification

## Rules

Experiments should be bounded and preferably reversible. Control variables when diagnosis matters. Experiment success does not equal production readiness. Preserve failures and surprises.

Learning loop:

`OBSERVATION → EXPERIMENT → RESULT → LESSON → CANDIDATE RULE → VALIDATION → RULE`

Never jump directly from one observation to a permanent rule without checking whether the lesson generalizes.
