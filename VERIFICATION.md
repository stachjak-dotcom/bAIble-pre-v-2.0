# Verification Record

Verification is evidence that a stated result was actually checked. It is separate from the agent's claim that the work is complete.

## Minimal record

- **Claim / result being verified:**
- **Expected result:**
- **Verification method:**
- **Evidence inspected:**
- **Actual result:**
- **Limitations:**
- **Status:**
- **Verifier:**
- **Date / revision / commit (when relevant):**

## Rules

- Verify the material part of the claim, not merely its appearance.
- Prefer reproducible checks when practical.
- Record limitations and failed checks.
- Do not call an experiment successful merely because output looks convincing.
- Agent self-report is not independent verification.
- Agreement between agents using the same evidence is not independent evidence.
