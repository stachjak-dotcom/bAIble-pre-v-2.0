# Private Workspace Template

This directory is a starting kit for a user's **private workspace**.

Copy these templates into your own private workspace/repository. Do not put your project-specific information into the public bAIble repository.

## Recommended information flow

PUBLIC bAIble
→ reusable governance

PRIVATE WORKSPACE
→ project context, decisions, experiments, evidence, handoffs, lessons

PRIVATE PROJECT
→ implementation and project-specific source of truth

SECURE SECRET STORE
→ credentials and secrets

## Start with

- PROJECT_CONTEXT.md
- PROJECT_STATE.md
- DECISIONS.md
- AGENT_SCOPE.md
- EXPERIMENT.md
- LESSONS_LEARNED.md

Add other records only when the project needs them.

## First private-workspace check

Before the first substantial task, verify:

- repository visibility is appropriate;
- the user knows who can access it;
- the project source of truth is identified;
- agent scope and authority are recorded;
- important information has a destination;
- secrets are not stored in ordinary files;
- the public bAIble repository will not be used as project memory.

The template is intentionally generic. Project-specific names, decisions, data, and implementation belong in the user's own private environment.
