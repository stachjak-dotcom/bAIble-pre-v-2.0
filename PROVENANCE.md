# Provenance

Every important claim should have an origin and a status.

## Source classes

- `PUBLIC-SOURCE` — publicly accessible source.
- `PROJECT-SOURCE` — source belonging to the current project/workspace.
- `EXPERIMENT` — evidence produced by a bounded experiment.
- `GENERALIZED-LESSON` — lesson generalized from prior work without exposing its private source.
- `PRIVATE` — intentionally excluded from this public repository.

Never cite a private source as if it were public. Never imply access to a source that the current agent cannot access.

## Minimal record

`Claim:`
`Status:` VERIFIED / ESTABLISHED / EXPERIMENTAL / PROPOSED / PRIVATE
`Source class:`
`Source:`
`Evidence:`
`Limitations:`
`Last verified:`

When provenance is uncertain, keep it uncertain rather than inventing a source.
