# Handoff

Use this format when transferring work between humans, agents, tools, or sessions.

## Role-aware handoff

A handoff is not only a progress note. It preserves the responsibility chain between roles. Record the sender's role, the receiver's role, and any authority or approval boundary that matters.

## Rules

1. Preserve scope and authority.
2. Preserve material uncertainty and unknowns.
3. Distinguish completed work from proposed next work.
4. Link claims to evidence where practical.
5. Never imply access, work, verification, or certainty that did not occur.

A receiving agent should be able to continue the bounded task without reconstructing hidden conversational context.
