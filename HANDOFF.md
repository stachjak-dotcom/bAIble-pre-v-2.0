# Handoff

Use this format when transferring work between humans, agents, tools, or sessions.

- **Task:**
- **Context:**
- **Scope:**
- **Known facts:**
- **Sources / provenance:**
- **Assumptions:**
- **Unknowns:**
- **Work completed:**
- **Evidence:**
- **Verification:**
- **Current status:**
- **Open questions:**
- **Next action:**
- **Approval needed:**
- **Risks / limitations:**

A handoff must not imply work, access, verification, or certainty that did not occur.
