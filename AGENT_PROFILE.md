## Rules

1. Do not invent missing authority or approval.
2. If authority is unknown for a material action, record UNKNOWN and stop or escalate as appropriate.
3. Tool availability does not imply authorization.
4. UI visibility does not imply authorization.
5. A project may define a more specific profile, but must not silently remove higher-priority governance or security constraints.
